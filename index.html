Molecular dynamics is calculus

The main tool of computational chemistry, in five blocks.

1Atoms are balls

Each atom is a ball with a position x(t). The outlined one feeds block 4.

step 0 · one frame of the movie per step

2The energy is a landscape

Hills and valleys: two atoms attract when apart and push back when squeezed. Move the pointer over the plot.

F = −dU/dx: minus the slope, so atoms roll downhill.

3Newton makes it a differential equation

m·x″ = −dU/dx

Acceleration is the second derivative of position, so F = ma is a differential equation for every atom at once.

Nobody can solve it by hand for thousands of atoms, so the computer takes tiny steps in time.

4Two Taylor series give the step

Expand x(t + dt) and x(t − dt), then add: the odd terms cancel and the error is of order dt4.

x(t + dt) =x(t) + v·dt + ½a·dt2 + ⅙b·dt3 + … x(t − dt) =x(t) − v·dt + ½a·dt2 − ⅙b·dt3 + … x(t + dt) + x(t − dt) =2x(t) + a·dt2 + …
x(t + dt) = 2x(t) − x(t − dt) + a(t)·dt2
